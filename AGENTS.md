# Project Instructions

## Puzzle Generation

For any future request to generate, draft, create, or import a new logic puzzle, use:

`prompts/puzzle-generation.md`

as the base specification before creating puzzle content.

Do not generate puzzle JSON from scratch without following that file.

The puzzle generation specification is the single source of truth for:

- puzzle structure
- story style
- clue quality
- uniqueness requirements
- anti-redundancy rules
- validation expectations
- output JSON format

Existing puzzle data, gameplay logic, and UI should not be changed unless the user explicitly asks for those changes.
